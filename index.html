Features

🗺️

Multiple Map Layers

Standard, Satellite, Cycle, and Transport views — all with offline tile caching.

📍

POI Discovery

Find cafes, pharmacies, bus stops, and more near you using the Overpass API.

📤

OSM Editor

Create and edit POIs directly on OpenStreetMap. OAuth 2.0 PKCE, check_date confirm, tag autocomplete.

🏃

Track Recorder

Record GPS tracks in real time. Live polyline, waypoints, GPX export, and direct OSM upload.

🏠

Building Editor

Draw building polygons by tapping vertices. 8 presets, upload directly to OSM. Mobile-first design.

🛣️

Road Editor

Draw roads vertex-by-vertex. 12 highway types, one-way support, color-coded by type.

🏘️

Address Mapper

Quick house number mapping with automatic street name detection. Batch mode for rapid surveying.

🎯

Quest Mode

StreetComplete-style quests. Find POIs with missing data and answer simple questions to improve the map.

📱

Installable PWA

Add to your home screen. Works offline with cached tiles. Native app experience.

📖

Beginner Friendly

Interactive 15-step tutorial, built-in tag reference, and bilingual interface (EN/EL).
