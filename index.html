Waymark

Explore. Map. Contribute.

A privacy-first Progressive Web App for discovering and contributing to OpenStreetMap. Works offline. No tracking. No ads. Ever.

Features

🗺️

Multiple Map Layers

Standard, Dark, Satellite, and Topographic views — all with offline tile caching.

📍

POI Discovery

Find cafes, pharmacies, bus stops, and more near you using the Overpass API.

📡

GPX Editor

Upload, view, edit, and download GPX tracks. All processing happens in your browser.

📝

OSM XML Export

Create .osc files ready for upload to OpenStreetMap via JOSM or iD editor.

📤

Direct OSM Upload

OAuth 2.0 PKCE authentication for secure, direct contribution to the map.

📱

Installable PWA

Add to your home screen. Works offline with cached tiles. Native app experience.

⚠️

Quality Checker

Identify data quality issues — unnamed roads, buildings without names, missing sources.

📖

Beginner Friendly

Interactive tutorial, built-in tag reference, and bilingual interface (EN/EL).

Built With
